# Amr Eldeeb Portfolio

A modern, dark-themed portfolio website showcasing my work as a Full Stack Developer & UI/UX Designer.

## 🚀 Features

- Modern UI with dark theme
- Interactive 3D Globe visualization
- Animated UI components
- Project showcase with 3D hover effects
- Responsive design
- Dynamic text animations
- Floating navigation
- Social media integration

## 🛠️ Built With

- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- Three.js
- React Three Fiber
